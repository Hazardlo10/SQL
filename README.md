# SQL

Примеры работы с реляционными СУБД: проектирование схем, хранимые процедуры, функции, аналитические запросы.

## MS SQL Server — Склад товаров

База данных для работы со складом товаров. Реализованы возможности добавления нового клиента (процедура AddPerson), покупки товара (процедура CreateOrder), а также расчёта загруженности склада в зависимости от времени (построение таблицы StoreState, процедура UpdateStore).

- `tables.sql` — создание таблиц
- `funcs.sql` — функции
- `procs.sql` — хранимые процедуры

## Oracle — Логистика РЦ → Магазины

Схема БД для управления логистикой сети розничных магазинов: распределительные центры, поставщики, остатки, заказы, движение товаров.

**Структура:**
```
oracle/logistics/
├── 01_tables.sql           — 14 таблиц: РЦ, магазины, товары, поставки, заказы, остатки, журнал движения
├── 02_procedures.sql       — хранимые процедуры: приёмка, заказ, отгрузка, списание, автозаказ
├── 03_functions.sql        — функции: остатки, оборачиваемость, прогноз дефицита, ABC-классификация
├── 04_views.sql            — представления: отчёты по остаткам, дефицит, KPI поставщиков, оборачиваемость
├── 05_analytics_queries.sql — аналитические запросы: ABC-анализ, когортный анализ, выявление аномалий
└── 06_seed_data.sql        — тестовые данные
```

**Ключевые процедуры:**
- `receive_shipment` — приёмка поставки на РЦ с пересчётом остатков
- `create_store_order` — формирование заказа магазина с проверкой наличия и резервированием
- `ship_order` — отгрузка заказа с РЦ, списание остатков
- `receive_at_store` — приёмка товара магазином
- `write_off_expired` — списание просрочки
- `generate_auto_orders` — автоматическая генерация заказов для магазинов с дефицитом

**Аналитика:**
- ABC-анализ товаров по объёму отгрузок
- Оборачиваемость и прогноз дефицита (days_until_stockout)
- Когортный анализ магазинов
- Выявление аномалий в заказах (z-score)
- KPI поставщиков
- PIVOT-матрица поставщик × категория
